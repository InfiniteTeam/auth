# @inftkr/shared

Shared constants and domain types for the
[inft-auth](https://github.com/InfiniteTeam/auth) platform.

Contains the platform-wide contract:

- `DOMAIN_AUTH`, `DOMAIN_ROOT`, `OIDC_ISSUER` — host/issuer constants
- `API_PREFIX`, endpoint-related constants
- `SESSION_COOKIE_NAME`, `SESSION_COOKIE_OPTIONS` — cookie contract
- web/bitfield and permission domain types (`Role`, `BitField`,
  `PermissionBitField`, ...)

This package must stay dependency-free so every consumer (backend, frontend,
SDK) can import it without pull-in.

## Development

```bash
pnpm build      # tsup
pnpm dev        # tsup --watch
pnpm typecheck  # tsc --noEmit + generated docs
pnpm docs       # API docs → docs/
```
