# @inftkr/auth-core

Shared authentication core for the [inft-auth](https://github.com/InfiniteTeam/auth)
platform: domain types, an API client for the session endpoints, guards (Nest)
and React hooks, all in one type-safe package.

## Features

- **`AuthApiClient`** — typed client for `/api/v1/session` and the LDAP /
  social sign-in endpoints
- **Nest guards** — `SessionGuard`, session resolution + role/permission checks
- **React hooks** — `useSession`, `useSignIn`, `useSignOut`
- **Shared types** — `Session`, `SessionUser`, `Role`, `PermissionBitField`

## Development

```bash
pnpm build      # tsup
pnpm dev        # tsup --watch
pnpm typecheck  # tsc --noEmit + generated docs
pnpm docs       # API docs → docs/
```
